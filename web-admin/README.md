# Web Admin — 后台管理界面

> 桌面女友项目的后台管理 Vue 应用。供项目方运营角色 / 用户 / 订单 / 资质审核使用。

## 技术栈

- Vite + Vue 3 + Element Plus + Pinia
- TypeScript 5

## 功能模块

- 角色管理(CRUD / 版本管理 / 上传资源 / 审核)
- 用户管理(查询 / 封禁 / 设备管理)
- 订单管理(查询 / 退款 / 流水)
- 资质审核(角色商店 license 审核工作流)
- 数据统计(下载量 / DAU / GMV / 转化率)

## 启动方式

```bash
cd web-admin
npm install
npm run dev    # 开发
npm run build  # 生产构建,产物在 dist/
```
